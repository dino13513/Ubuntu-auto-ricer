# Ubuntu-auto-ricer
a ubuntu auto ricer i made for my class its a simple kde install with optional sober and steam preinstall

HOW TO USE:
  
  first run any sudo command in terminal to make sure your terminal sesstion is "authorized"(it stops asking for sudo password when using sudo for a while)
  then just run this "curl -sSL https://github.com/dino13513/Ubuntu-auto-ricer/blob/main/ubuntu.sh | bash"
